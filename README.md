## Currently building

### Glaze by Sugarcoat
**A clear view of your services.**

[Glaze](https://github.com/anandchauhan21/Glaze) is an open-source, self-hosted monitoring tool that turns HTTP and optional browser checks into a readable dashboard.

- KPI cards, response-time charts, and recorded check outcomes.
- Clear warnings for stale or missing monitoring data.
- Private access through SSH, with no AI model or GPU required.
- Python standard library, curl, and optional Chromium; MIT licensed.

**[Explore Glaze →](https://github.com/anandchauhan21/Glaze)**
